Methodology and limits

  • Static string and DOM checks only. Cannot measure exact color contrast, focus visibility, timing, or screen-reader speech.
  • Checks marked Manual need a person to confirm: contrast (measure to 7 to 1), reading level (aim for grade 9 or lower), and no-timing (confirm no timeouts).
  • Always confirm with axe DevTools, a keyboard-only pass, 400 percent zoom and 320 pixel width, and NVDA, JAWS, and VoiceOver.

3. Glossary and help

Plain language help. Each hard word is defined once, then reused.

WCAG
Web Content Accessibility Guidelines. The world-wide test for usable web pages. A is basic, AA is the law in most places, AAA is the highest.
Screen reader
Software that reads the page out loud, like NVDA, JAWS, or VoiceOver. It needs names for buttons, labels for inputs, and alt text for images.
Alt text
Short text that stands in for an image. Example: alt="Team photo, four people smiling". Never use "image" or "preview".
CORS
Cross-Origin Resource Sharing. A browser safety rule that may block Fetch URL. Fix: copy page source and use Paste HTML.
Focus indicator
The thick outline that shows where the keyboard is. This tool uses a 3 pixel dark-blue outline.
P0 blocker
A fail that blocks disabled users. Fix P0 first, then P1, then P2.
Help with Level, Severity, and Show passed

Minimum level: A plus AA plus AAA shows all checks. AA plus AAA hides basic A checks. AAA only shows the hardest checks.

Severity: All shows all. P0 shows blockers only. P0 plus P1 hides low-risk P2 advice.

Show passed: on shows green PASS rows too. Off shows fails only. Changes apply only after Apply filters.

Help when Fetch URL fails
